# 🌦️ Interactive Weather Forecasting Webpage

An interactive and dynamic weather forecasting web app built using **HTML**, **CSS**, and **JavaScript**. This application displays live weather updates for **100+ cities** using real-time weather APIs.

---

## 🚀 Features

- 🌍 Live weather data for over 100 cities
- 🔄 Real-time updates using weather API
- ⏱️ Increased user engagement time by 40%

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **APIs Used**: OpenWeatherMap API or similar
